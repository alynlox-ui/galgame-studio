⚙ 数值管理（Flag）

数值是分支与结局判定的基础。例如创建「小夜好感」，初始为 0；在场景或选项中 +1；在条件中写「小夜好感 >= 2」。

📖 快速上手

1. 场景：左侧列表管理剧情节点；中间画布可拖动节点、滚轮缩放、拖拽空白平移。
2. 连接：在右侧面板设置「默认下一场景」；「选项」可创建带文字的分支；「自动分支」按条件（Flag）跳转，用于结局判定。
3. 数值：点击「数值管理」创建 Flag（如 好感度）。在「进入时设置数值」或选项里对其加减。条件示例：好感度 >= 3 && 勇气 > 1
4. 结局：勾选「本场景是结局」，到达该场景即进入结局画面。
5. 播放：点「运行测试」。播放器支持 快进 / 后退 / 历史 / 自动 / 存档读档（浏览器本地）。点击「🎭 演示模式」可在游戏画面中直接点击并拖动背景/角色立绘/文本框/角色名牌/选项区，上传图片，调整位置、缩放、透明度、配色、字号等 UI 样式，修改自动同步回项目。
6. 导出：项目可导出为 JSON 文件永久保存，也可再导入继续编辑。
